灰蓝十八键 · 同文 Trime
适配目标：Trime 3.3.13；按提供的截图制作灰蓝底色、白色圆角键帽和蓝色回车。

一、通过 Git 使用

1. 平板拉取仓库后，让同文的用户数据目录使用 rime-config/rime/ 中的配置。
   若拉取目录与同文数据目录分开，更新后将这里的配置和资源同步到同文数据目录。
   以下路径均相对于 rime-config/rime/：
     soft_blue_18.trime.yaml                 主题及键盘布局
     fonts/SoftBlue18.ttf                    字母和图标字体
     fonts/SoftBlue18-OFL.txt                字体许可证
     backgrounds/soft_blue_18/              日夜配色的键帽背景
     double_pinyin_flypy_18.schema.yaml      小鹤十八键方案
     double_pinyin_flypy_18.custom.yaml      万象语法参数
   方案引用的 rime_ice.dict.yaml、cn_dicts/ 和 lua/uuid.lua 均沿用仓库现有文件。
2. 万象模型 wanxiang-lts-zh-hans.gram 不随 Git 同步，首次使用需单独复制到
   同文用户数据目录根目录，与方案文件并列。后续拉取仓库不必重复复制模型。
3. 在同文的方案设置中启用“小鹤双拼18键”。也可在平板本地的
   default.custom.yaml 中，把下面这一项加入现有 patch/schema_list 列表：
     - schema: double_pinyin_flypy_18
   default.custom.yaml 是设备本地文件，被 Git 忽略；按各设备需要维护方案列表。
4. 在同文执行“重新部署”，首次编译词库需要等待。
5. 主题选“灰蓝十八键”，配色选“灰蓝 · 日间”或“灰蓝 · 夜间”，
   输入方案选“小鹤双拼18键”。若看不到小字提示，开启按键助记/符号提示。

二、操作

中文分组：
  Q  WE  RT  Y  U  IO  P
     A  SD  FG  H  JK  L
  分词  Z  XC  V  BN  M  退格

合并键发送 Xime 官方小鹤十八键方案使用的小写代表码，例如 WE → w、BN → b。
中/英键切换到完整英文 QWERTY；底部可切换数字、符号页。
上滑 Z / XC / V / BN / M：全选 / 复制 / 粘贴 / 段首 / 段尾。
长按字母输入小字提示的符号；长按 XC 剪切、V 打开剪贴板。
空格可左右滑动移动光标，长按调用系统语音服务。
工具栏：设置 / 主题 / 方案 / 剪贴板 / 配色 / 撤销 / 收起。

主题 style 中可调 keyboard_height（竖屏 260 dp）、keyboard_height_land
（横屏 240 dp）和 keyboard_padding_land（横屏左右留白 16 dp）。
外接键盘按普通 26 键小鹤输入时，需另外启用并切换到普通小鹤方案。
本主题未修改候选窗定位；剪贴板、编辑快捷键和语音服务取决于目标应用与系统。

三、维护与验证

资源生成脚本：others/script/theme/soft_blue_18.py
运行：python others/script/theme/soft_blue_18.py
脚本校验合并键编码、行宽、跳转、字体与图片引用，并生成键帽和一张日间预览。
重建字体时，额外传入 --font-source Nunito.ttf --font-license OFL.txt。

主题已通过 trime-cli 配置及字体校验，并在隔离目录用 Rime 引擎编译词库、
加载万象模型，验证“你好、中国、世界、输入、你好世界”的十八键输入。
本机 make lint 受 Windows bash/WSL 启动权限限制，已直接用仓库规则运行 yamllint。
preview-default.png 是配置和实际资源的电脑渲染图，尚未在 Android 平板实测。
